# Участие в проекте

## Что приветствуется

- Новые правила для реальных чит-клиентов, особенно русскоязычных.
- Уточнение существующих признаков: пути классов, имена процессов.
- Тесты на ложные срабатывания.
- Исправления в сканере и отчётах.
- Переводы документации.

## Чего в репозитории быть не должно

- Исполняемых файлов, `.exe`, `.dll`, архивов с бинарниками.
- Ссылок на скачивание читов, «кряков» и приватных сборок.
- Чужих персональных данных: ников, почт, IP, конфигов игроков.
- Правил, которые ловят ванильные файлы Minecraft.

Пул-реквест с бинарником будет закрыт без обсуждения.

## Порядок работы

1. Форкните репозиторий и создайте ветку:
   ```bash
   git checkout -b rule/my-client
   ```
2. Внесите изменение. Для нового правила обновите
   `signatures/cheats.json` и, если нужно, `docs/DETECTIONS.md`.
3. Запустите тесты:
   ```bash
   python3 -m unittest discover -s tests -v
   ```
4. Проверьте базу и отчёт:
   ```bash
   python3 -m rwcd rules
   python3 -m rwcd scan . --no-processes --fail-on none
   ```
5. Откройте пул-реквест с описанием: что за клиент, откуда он известен,
   какой признак используется и насколько он устойчив.

## Стиль кода

- Python 3.10+, стандартная библиотека, без новых зависимостей без причины.
- Комментарии и docstring — по-русски, идентификаторы — латиницей.
- Пользовательские строки (отчёты, ошибки) — по-русски.

## Лицензия вклада

Отправляя пул-реквест, вы соглашаетесь, что ваш вклад распространяется
под лицензией MIT, как и остальной проект.
