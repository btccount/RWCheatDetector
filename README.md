# RWCheatDetector

[![CI](https://github.com/btccount/RWCheatDetector/actions/workflows/ci.yml/badge.svg)](https://github.com/btccount/RWCheatDetector/actions/workflows/ci.yml)
[![Лицензия: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Python 3.10+](https://img.shields.io/badge/python-3.10%2B-blue.svg)](pyproject.toml)

Открытый детектор чит-клиентов Minecraft. Проверяет JAR-файлы в папке игры,
содержимое архивов и запущенные процессы по базе сигнатур. Ничего не запускает,
не распаковывает на диск и не отправляет данные в сеть.

## Что это

`rwcd` — консольная утилита для предварительной проверки клиента Minecraft.
Она отвечает на вопрос «есть ли в этой папке файлы, похожие на известные
чит-клиенты», а не «читерит ли игрок». Решение всегда принимает человек.

## Чем это не является

- Это **не античит** и не серверный плагин: утилита работает только с тем, к чему
  есть доступ на диске и в списке процессов.
- Это **не доказательство** читерства. Имя JAR подделывается за секунду,
  а приватную сборку база может не знать.
- Утилита **не обходит** защиты и не пытается обнаружить то, что спрятано
  в памяти или загружено с сервера.

## Возможности

- Поиск JAR-файлов в `.minecraft`, `mods` и любом указанном каталоге.
- Три способа сопоставления: имя файла, SHA-256 и пути классов внутри архива.
- Проверка запущенных процессов (Windows и macOS/Linux).
- Текстовый отчёт на русском и JSON для интеграций.
- Код возврата, пригодный для CI и скриптов.
- База сигнатур — обычный JSON, который можно расширять без правки кода.

## Установка

Нужен Python 3.10 или новее. Сторонних зависимостей нет.

```bash
git clone https://github.com/btccount/RWCheatDetector.git
cd RWCheatDetector
python3 -m pip install -e .
```

Без установки:

```bash
python3 -m rwcd scan ~/.minecraft
```

## Использование

Проверить стандартную папку игры:

```bash
rwcd scan ~/.minecraft
```

Проверить только JAR и не трогать процессы:

```bash
rwcd scan ./mods --no-processes
```

Сохранить отчёт в JSON:

```bash
rwcd scan ~/.minecraft --json > report.json
```

Упасть с кодом 1, если найден уровень `medium` или выше (удобно для CI):

```bash
rwcd scan ~/.minecraft --fail-on medium
```

Посмотреть загруженную базу:

```bash
rwcd rules
```

### Коды возврата

| Код | Значение |
| --- | --- |
| `0` | Совпадений уровня `--fail-on` и выше нет |
| `1` | Найдено совпадение указанного уровня |
| `2` | Ошибка: нет пути, битая база сигнатур |

## Пример отчёта

```text
RWCheatDetector 1.0.0
Проверено: JAR-файлов — 42, процессов — 318
Найдено совпадений: 1

[ВЫСОКИЙ] Nursultan
  правило:   nursultan
  тип:       содержимое JAR
  объект:    /home/user/.minecraft/mods/client.jar
  признак:   nursultan/Client.class
  описание:  RU-чит-клиент для анархии, известен по сборкам под 1.16.5…
```

## Загрузка файла в релиз

Скрипт для сопровождающих: открывает системный диалог выбора файла и прикрепляет
его к релизу. Репозиторий и тег определяются автоматически.

```bash
./scripts/release-upload.sh                          # последний релиз + выбор файла
./scripts/release-upload.sh v1.0.0 ./dist/pkg.tar.gz # тег и файл аргументами
./scripts/release-upload.sh --clobber --file ./report.json
./scripts/release-upload.sh --dry-run --file README.md
```

В Finder можно дважды кликнуть `scripts/Загрузить в релиз.command`.
Если релизов ещё нет, скрипт предложит создать первый.

## База сигнатур

Файл [`signatures/cheats.json`](signatures/cheats.json) содержит правила для
известных клиентов, включая русскоязычные сборки: **Nursultan**, **Expensive**,
а также Wurst, Meteor, Future, RusherHack, Impact, Vape, Apollo, Delta.
Отдельно помечены Baritone и X-Ray как «средний» уровень: это не всегда
чит-клиент, но на многих серверах запрещено.

Как добавить своё правило — в [docs/SIGNATURES.md](docs/SIGNATURES.md).
Что именно ищет каждое правило — в [docs/DETECTIONS.md](docs/DETECTIONS.md).

## Ограничения

- Ложные срабатывания возможны: правило `generic-cheat-name` реагирует на слова
  `cheat`, `hack`, `killaura` в имени файла.
- Пропуски тоже возможны: приватные сборки, переименованные классы и инжекторы
  не всегда совпадают с сигнатурами.
- Проверка процессов видит только имя исполняемого файла, а не его содержимое.

## Безопасность

В этом репозитории **нет и не будет** исполняемых файлов: только Python-код,
JSON и документация. Релизы содержат исходники, а не `.exe`.

Если где-то предлагают скачать «RWCheatDetector.exe», «официальный установщик»
или просят отключить антивирус — это подделка. Подробнее в [SECURITY.md](SECURITY.md).
